## Findings

- [ ] **DBL-001 (P2, reproduced API/contract candidate):** [MariaDB recursive CTE](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376729437) and other four drivers reject a bound legitimate recursive UNION ALL via raw SQL heuristic. Inspect structured CTE API, compiler and documented raw contract; support safe structural representation without weakening injection policy; native SQL comparison, tenant bindings, recursive termination/depth, hostile fragments rejected.
- [ ] **DBL-002 (P1 potential scope/integrity issue, not confirmed leak):** [derived query](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376800229) Derived filter escaped scope, expected [6,8,16,18]. Capture SQL, bind values/types and qualified pluck output; compare native query and exact rows across five drivers. Fix compiler or projection only after isolation; no tenant data leakage or duplicate rows.
- [ ] **DBL-003 (P1 candidates):** [uncertain COMMIT](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376801297), [MySQL TLS](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376799754), [proxy session](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376902805), [proxy transaction](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376908255); distinguish driver errors, native peer trust, transaction ambiguity/lease state and fixture. Ensure no blind commit replay, exact durable effects and connection cleanup. Investigate group election/quorum, MaxScale/Galera/SQL Server AG individually against genuine topology.
- [ ] **DBL-004 (P2):** historical right outer join inline alias misuse corrected with addSelectAs; all five composite FK controls now pass after exact exception correction. Retest joins, constraints, migrations, native prepared statements, rollback, deadlocks, replica weights/lag, pooling and query cache. Pgpool ordinary/failover and primary promotion qualified (latest run); do not file those as DBLayer bugs.
- [ ] **DBL-005 (cross-owner):** Foundation DISTINCT JSON and PAT poisoned transaction are Foundation-owned queries, MFA schema width Foundation-owned. See [Foundation](foundation.md); regression interoperability only. External SQL Server HA remains infrastructure blocked.
