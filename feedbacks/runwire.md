# Runwire — production feedback and upstream action plan

Status: **open — Runwire 4.0 removal and retained-scope qualification** · 2026-11-26

Baseline: 3.1 (full-run install evidence). Upstream target: breaking 4.0 candidate, not 3.1.1. No publication authorized.

## 4.0 scope and qualification

Upstream [PR #18](https://github.com/infocyph/Runwire/pull/18) and [implementation tracker](https://github.com/infocyph/Runwire/blob/fix/production-feedback/qa/release-baseline/production-feedback-plan.md) authorize complete removal of native HTTP/3, QUIC, QPACK and ext-quic. Preserve HTTP/1.1, HTTP/2, gRPC, WebSocket, TLS, TCP/UDP, process/coroutine/host functionality and security policy. Public HTTP/3 may terminate at an independent edge; do not treat this as native Runwire support.

- [ ] Enumerate precisely the retired H3/QUIC-only contracts, including mixed scenario components; preserve every applicable H1/H2, generic UDP, host, security and lifecycle assertion and the historical frozen inventory.
- [ ] Update downstream version constraints, API calls and qualification configuration in compatible candidate branches; do not alter released-package assumptions prematurely.
- [ ] Freeze exact candidate identity before launch; verify resolved package references without dependency revision pins. Qualify all retained runtime tuples and six JWKS checks.
- [ ] Trace previous 17 workload assertion failures (16 runtime, one authentication); retire only confirmed removed-feature cases with evidence. The other 201 failures were at preparation, not proven library defects. Prior [candidate run](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45807289870): 96 passed, 218 failed; not final evidence.
- [ ] Final published-package rerun and matched common-scope benchmark/soak; sync trackers and review feedback. No automatic merge.

Implementation evidence: upstream commit [ad154e4](https://github.com/infocyph/Runwire/commit/ad154e4052e5ed682e5ffa717fbb82021ff709e9) removes dispatcher H3 routing and passed all nine triggered checks; [2fcc1ec](https://github.com/infocyph/Runwire/commit/2fcc1ece8d821fb4e4e698e9ac5ceb1c15a63daa) removes direct H3 client and moves retained H1/H2 profiling into independent CI; all nine triggered workflows passed. Coordinated removal commit [629380b](https://github.com/infocyph/Runwire/commit/629380bf137fa0b90ce010ecbd16d69056ffa9d5) removes the remaining inbound transport, QUIC/QPACK, executor IPC, dependency provisioning and dedicated protocol tests; retained H1/H2 and generic UDP lifecycle tests remain. Source files: 451 to 377 versus published 3.1. Exact-head upstream QA has been triggered; consumer adaptation, retained-scope qualification and publication gates remain open.

## Historical findings (retained scope remains open)

- [ ] **RUN-001 (P1 protocol candidate, repeatable):** [strict H2](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45756151480/job/139695176565) reports HTTP/2 server must not send ENABLE_PUSH. Capture exact initial SETTINGS, value, order, frame and peer version. RFC 9113 §6.5.2 permits server value 0 but not 1; inspect decoder and state machine rather than altering valid peer. Verify H2 strict/fallback/reverse ALPN, omitted/zero/one setting, malformed settings, proper connection errors and no silent downgrade. H1 and H3 positive controls pass.
- [ ] **RUN-002 (P1 candidate):** [parallel multiplex](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376669387), [flow control](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376669341), [deadline](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376669438), [ping](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376669603); historical H2 multiplex/negotiation families may cascade from RUN-001, do not count separately before handshake fix. Observe peer events, same socket, stream IDs, independent body/status and flow-control windows; test cancel/reset/drain, HEAD, timeout, concurrent failures, no orphan streams.
- [ ] **RUN-003 (P1 candidate):** outbound [H2 HEAD](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376979305), [disconnect](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376983223), [H1 short](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376981265), [H1 retry](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376978479). Numeric dialer capture LAB-004 corrected; H1 GET now passes. Distinguish fixture from framing, retry safety, approved peer, redirect, timeout and response settlement. Preserve no blind replay and exact response bytes.
- [ ] **RUN-004 (P1 candidate):** [Foundation pool crash](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376705949), rate-limit/circuit [hosted job](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376706284), [hosted job](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376708415). Trace runtime process and policy ownership; test worker recycle, cancellation, reaping, backpressure and lease recovery. See [Foundation](foundation.md).
- [ ] **RUN-005 (security integration):** Epicrypt remote JWKS needs approved peer identity across DNS/connect, see [EPC-001](epicrypt.md). Verify actual peer before HTTP bytes, verified TLS name, redirect reapproval and retained H1/H2 parity. Native H3 is removed by 4.0; historical H3 results are not current acceptance. No bypass of caller security policy.
- [ ] **RUN-006 (retest):** QUIC provisioning corrected and native inbound/outbound H3 pass; dual-stack peer fixture fixed. QUIC aggregate/flow/reset/drain cases are candidates for retirement with explicit evidence once native removal is complete; native admission and process/host/coroutine cases remain mandatory. Extension availability is not a runtime defect.

Keep frozen 2,177 routine tuples and two native gRPC modes; add only justified regression cases. Run published-package consumer tests on PHP 8.5 and supported upstream CI versions; final full matrix after upstream releases. Keep fixture/third-party fixes separate. Historical original handoff did not implement upstream changes; current upstream progress is linked above.
