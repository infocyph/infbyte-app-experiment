## Findings

- [ ] **WEB-002 (P1 candidate reproduced on both matchers):** [fused](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45756151480/job/139695177881), [sharded](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45756151480/job/139695177858) Route attribute middleware was discarded. [Workload](../qa/workloads/ecosystem-route-boundaries.php) registers attribute route and middleware; domain/resource/constraint controls passed. Inspect attribute reader, route registration metadata and compiled cache hydration; verify dynamic/fused/sharded parity, middleware order, negative authorization and CORS/rate policies. No dropping attribute metadata or weakening gate.
- [ ] **WEB-001 (P1 candidate):** [signed invalid expiry](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376707130) Signed response did not match handler; signed permanent/rotation/tamper/canonical/composition/leeway/temporary/relative/retired-key families fail. Capture actual response status/body and canonical request/clock/key registry; compare generated URL and independent signature, same handler in dynamic/compiled modes. Preserve expiry, duplicate query, host/path binding, rejection and key rotation.
- [ ] **WEB-003 (P1 candidate):** [compiled preflight](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376707331), [negotiation](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376707519), [method/domain](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376712951), [middleware](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376716597). Compare middleware state/cache metadata and request host/method; retain 404/405/OPTIONS/HEAD, exact Vary, CORS and security policy composition. Latest route CORS control passes; not full policy certification.
- [ ] **WEB-004 (P1 integration):** [CSRF 419](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376788588) and browser HTTP 500 [hosted job](https://github.com/infocyph/infbyte-app-experiment/actions/runs/45661843498/job/139376719489); diagnose Foundation readiness/session/cookie and route errors independently. All six host policy trace controls passed in latest qualification; app-ready and auth integration remain separate. See [Foundation](foundation.md).
- [ ] **WEB-005 (P2 regression):** file/stream and gateway risk admission: exact range, HEAD, uploads, content negotiation, compression, cache validators, cookie policies, route-specific pre-bcrypt risk checks, trusted edge identity. Route storage/host failures to [Pathwise](pathwise.md) or [Runwire](runwire.md) when independently established.
